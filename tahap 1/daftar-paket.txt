DAFTAR PAKET - HOST CONTAINER MINI (TAHAP 1)
============================================

A. 10 PAKET UTAMA SESUAI TEMA (distro pengembang container)
-----------------------------------------------------------
No  Paket         Alasan pemilihan
1   runc          Runtime container standar OCI; inti untuk menjalankan container.
2   iproute2      Perintah "ip" untuk network namespace, veth, dan routing container.
3   cgroup-tools  Membuat dan melihat cgroup (cgcreate, cgget, dll.) untuk membatasi sumber daya.
4   containerd    Manajer container yang memakai runc; pelengkap runtime.
5   iptables      Aturan NAT dan firewall untuk jaringan container.
6   bridge-utils  Membuat bridge (brctl) untuk menghubungkan antarcontainer.
7   busybox       Toolbox mini; dipakai sebagai rootfs kecil untuk menguji container.
8   curl          Mengunduh rootfs/image dan menguji koneksi dari dalam container.
9   htop          Memantau proses dan penggunaan CPU/RAM (membantu mengamati cgroup).
10  vim           Penyunting teks untuk mengubah berkas konfigurasi (config.json runc, dll.).

Perintah pemasangan:
  apt install -y runc iproute2 cgroup-tools containerd iptables \
                 bridge-utils busybox curl htop vim
